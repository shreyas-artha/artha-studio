Artha Studio

Artha Studio is a personal desktop application used by its developer to publish short business-history videos to the developer's own YouTube channel, Artha Rewired, and to read that channel's public statistics. It is not offered to the public and has no users other than the developer.

Privacy Policy

Last updated: 5 November 2026

Data accessed. With the owner's consent through Google sign-in, the application uses the YouTube Data API to upload videos to the owner's channel and to read the public statistics of those videos.

Data stored. An OAuth token for the owner's account and the IDs and public statistics of the owner's own videos are stored on the owner's computer. No data about any other person or channel is collected.

Data sharing. No data is shared with third parties, sold, or used for advertising.

Deletion. Deleting the application's local files removes all stored data. Access can also be revoked at any time at https://myaccount.google.com/permissions.

YouTube API Services. Artha Studio uses YouTube API Services. By using it, the owner agrees to be bound by the YouTube Terms of Service. Google's handling of the data is described in the Google Privacy Policy.

Google API Services User Data Policy. Artha Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
